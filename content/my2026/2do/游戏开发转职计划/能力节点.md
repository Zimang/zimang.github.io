# 基础工程能力

| 模块     | 具体能力             | 验收标准（C1）                 | 为什么要验           |
| -------- | -------------------- | ------------------------------ | -------------------- |

|          | OnEnable / Disable   | 知道对象池/UI中的作用          | 实战常见             |
