# 指导意见

用稳定现金流换准备时间，用外部反馈替代主观判断，在风险持续下降的前提下，逐步逼近跳槽与独立开发的可行窗口。

核心意图只有三点：

1. **不把未来押在单次决策上**（拒绝裸辞 / 豪赌）
2. **所有升级动作必须有可验证的前置条件**（能力、市场、现金）
3. **允许失败，但不允许风险放大**

换句话说：

- 跳槽 ≠ 必须发生
- 独立开发 ≠ 必须盈利
- 唯一必须发生的事是：**确定性在一年内显著增加**



## 验收

原则

1. 只验收可评估的标准
   1. 能运行
   2. 能讲清
2. 验收下限而非上线
   1. 不要最好
   2. 必须做到不会一碰就碎
3. 每一条验收，都直接对应一个真实风险



## 关键节点

### 轨道节点

决定：**我是否还在当前人生轨道上**

| 节点 | 时间窗口 | 决策内容                 |
| ---- | -------- | ------------------------ |
| T1   | 2026 Q1  | 是否继续“转游戏开发”轨道 |
| T2   | 2026 Q3  | 是否允许为转岗承担风险   |
| T3   | 2027 Q2  | 是否正式切换职业身份     |

👉 **每个 T 节点，最多只能通过一次**
 👉 一旦否决，至少半年内不再讨论





### 能力节点

决定：**我有没有资格谈下一步**

| 节点 | 时间    | 本质问题                     |
| ---- | ------- | ---------------------------- |
| C1   | 2026.02 | Unity 是否被你掌控           |
| C2   | 2026.06 | 是否具备初级游戏开发交付能力 |
| C3   | 2026.12 | 是否达到可被雇佣状态         |

👉 C 节点可以重复
 👉 不通过就补强，不允许跳层



### 风险节点

决定：**我是否可以放大动作**

| 节点 | 时间    | 风险级别          |
| ---- | ------- | ----------------- |
| R0   | 现在    | 仅时间风险        |
| R1   | 2026.04 | 时间 + 精力       |
| R2   | 2026.10 | 现金流 + 简历暴露 |
| R3   | 2027.03 | 离职风险          |

👉 **风险节点必须由能力节点触发**
 👉 禁止“先 R 后 C”

| 风险类型 | 是否可逆  | 举例                     |
| -------- | --------- | ------------------------ |
| 时间风险 | ✅ 可逆    | 学了半年发现不合适       |
| 精力风险 | ⚠️ 半可逆  | 长期高负荷导致状态下滑   |
| 机会风险 | ❌ 难逆    | 错过应届/年龄窗口        |
| 生存风险 | ❌❌ 不可逆 | 现金流断裂、被迫降级工作 |
